RANK IS NOT FLAVOUR

等级，
不是味道。

分级制度回答的是“它从哪里来、按什么规则标、陈了多久”，不是“它好不好喝”。同一套等级里可以有平庸酒，也可以有杰作。这一页把法律、产区、酒庄和时间四种“等级”拆开。

01法律等级LAW

AOC / DOCG / DOCa / Prädikat 等产区法规

02产区 / 村庄 / 园PLACE

Village、Premier Cru、Grand Cru、AVA、GI

03酒庄 / 品牌分级ESTATE

1855、圣埃美隆、VDP、Langton's 等

04年份 / 酒龄 / 风格TIME

Vintage、Reserva、VSOP、XO、Prädikat

≠

分类不是评分。
AOC / DOCG / XO 都不是百分制。

最重要的一句：这些层级不是同一条质量分数线。它们回答的问题不同。

01它是法律等级，还是私人评选？

AOC/AOP、DOCG、DOCa 是法规；1855、VDP、Langton's 是历史或机构名单。

02它评的是地、酒庄，还是酒？

Grand Cru 往往是地块；Cru Bourgeois 是酒庄；Reserva 是陈年时间。

03它一定和味道正相关吗？

不一定。等级是入口，不是结论。年份、酿造、储存状态都能改写结果。

以下为常见规则的编辑整理，不是法规全文；AOC/AOP、DOCG 等具体标签以最新产区和瓶标为准。

01

FRANCE / 法国

先把“法律”
和“名庄”分开。

法国同时存在法律产区等级、历史酒庄排名和地块等级。它们不是同一套系统，经常被混着读。

AOC / AOP法定产区

产地、品种、产量、酿造和标签被规定；最高法律产区等级，不等于是最好喝。

IGP地区餐酒

产区范围更大，规则更灵活；很多性价比酒和实验性酒在这里。

VIN DE FRANCE法国日常餐酒

最宽的法律类别；可以好喝，也可以只是日常。

BORDEAUX / 波尔多

1855 年，一张给商人看的价目表。

1855

梅多克与苏玳分级

为巴黎世界博览会整理，按当时价格与声誉把酒庄分成一级到五级。红葡萄酒一级庄最初四家，1973 年木桐从二级升为一级；白葡萄酒另有苏玳/巴萨克分级。

GRAVES

格拉夫分级

1953 年制定、1959 年修订，列出格拉夫产区的列级酒庄；只覆盖一小部分酒庄，不能代表整个波尔多。

SAINT-ÉMILION

圣埃美隆分级

会周期性修订，分为 Premier Grand Cru Classé 与 Grand Cru Classé；名单会变动，甚至有酒庄退出。它评的是酒庄，不是所有右岸酒。

一句话：1855 是历史排名，不是每年重考；标着“Grand Cru”的波尔多酒也不一定属于 1855 分级。

BURGUNDY / 勃艮第

这里分级的是地，不是城堡。

01地区级RÉGIONAL

Bourgogne 等大区酒，范围最广。

02村庄级VILLAGE

标注具体村庄，如 Gevrey-Chambertin。

03一级园PREMIER CRU

村庄内被认定的地块，标“1er Cru”。

04特级园GRAND CRU

如 Chambertin、Musigny、Montrachet；是地块，不是酒庄头衔。

同一个特级园可以由不同酒庄装瓶；地块等级高，不代表每一瓶都好。 producer、年份和储存同样关键。

CHAMPAGNE / 香槟

村庄有“特级/一级”，酒没有一条官方质量阶梯。

香槟区有被列为 Grand Cru 和 Premier Cru 的村庄；历史上还有“échelle des crus”按村庄评级定价，但今天不再是简单的价格保证。它评的是村庄，不是每一家酒庄或每一瓶酒。

香槟更常按 甜度（Brut Nature → Doux）、年份（NV / Vintage）和 风格（Blanc de Blancs / Blanc de Noirs / Rosé）来读。Prestige Cuvée 是酒庄的旗舰系列，不是法律等级。

村庄级Grand Cru / Premier Cru甜度Brut Nature → Doux年份NV / Vintage
ALSACE阿尔萨斯特级园

Grand Cru 是划定园区；不是所有阿尔萨斯酒都能标。

RHÔNE罗讷“Cru”

Côte-Rôtie、Hermitage、Châteauneuf-du-Pape 等是产区名，不是一条统一质量阶梯。

LOIRE卢瓦尔 AOC

Sancerre、Vouvray、Chinon 等按产区和风格读，不以“等级”排序。

02

SOUTHERN EUROPE / 南欧与德国

DOCG 不是
“第一名”。

意大利、西班牙、德国、葡萄牙各有自己的法律等级；字母越多，只说明规则越具体，不自动等于越好喝。

ITALY意大利
DOCG法定产区最高法律等级；规则最严，不等于质量排名
DOC法定产区；覆盖大量传统酒
IGT地区餐酒；超级托斯卡纳常在此
Vino日常餐酒

Barolo、Barbaresco、Chianti Classico、Amarone 等都有 DOCG；但同一 DOCG 内风格差异极大。“Classico”指历史核心区，“Riserva”通常指更长陈年。

SPAIN西班牙
DOCa最高法律产区等级；目前只有少数产区
DO法定产区，数量最多
VPVino de Pago，单一庄园
VdT地区餐酒

Rioja 的 Crianza / Reserva / Gran Reserva 是陈年时间标识，不是质量分数；Ribera del Duero、Priorat 也各有规则。

GERMANY德国
Prädikat按成熟度/含糖量分级：Kabinett → TBA
Qualitätswein优质酒；可干可甜
Landwein / PGI地区餐酒

Kabinett、Spätlese、Auslese、Beerenauslese、Eiswein、Trockenbeerenauslese 是按采收成熟度分级，不是“越甜越高级”。VDP 是私人协会分级，不是法律。

PORTUGAL葡萄牙
DOC法定产区
IGP地区餐酒
Vinho日常餐酒

波特酒是加强酒，另有 Vintage、LBV、Tawny、Colheita、Ruby 等风格/陈年标识；它们不是同一套“DOC 等级”。

READING NOTE

DOCG / DOCa / Prädikat 都是“法律分类”，不是品鉴评分。它们告诉你生产规则、产地或成熟度；好不好喝仍然要看具体酒款、年份和状态。

03

NEW WORLD / 新世界

很多“等级”，
只是地理边界。

美国、澳大利亚、新西兰、智利、阿根廷、南非的法定体系主要保护“产地名称”，很少有欧洲那种法定质量阶梯。

国家法定产地体系官方质量等级？常见私人/市场标签
美国AVA（美国葡萄种植区）没有Meritage、酒庄 Reserve、评分
澳大利亚GI（地理指示）没有Langton's Classification（私人）
新西兰GI没有单一园、酒庄 Reserve
智利DO / GI没有统一质量阶梯Reserva、Gran Reserva、Icon
阿根廷IG / DO没有统一质量阶梯Reserva、Single Vineyard
南非WO（Wine of Origin）没有Reserve、酒庄分级

“Reserve / Reserva”在新世界没有统一法律定义，可能只是酒庄的产品线名。看到它，不要自动当成“更高级”。

04

SPIRITS / 烈酒

干邑的等级，
是时间和产区。

干邑、雅文邑、威士忌、龙舌兰和金酒各有自己的标签逻辑；最容易被误读的是“XO = 最好”和“年份越老越好”。

COGNAC / 干邑 AOC + 产区 + 酒龄

干邑是法国 AOC。产区分为 Grande Champagne、Petite Champagne、Borderies、Fins Bois、Bons Bois、Bois Ordinaires；“Fine Champagne”指大香槟与小香槟的调配，不是“香槟起泡酒”。

VS至少 2 年
VSOP至少 4 年
XO至少 10 年
HORS D'AGE通常更老，无法定统一年限

“Napoléon”在干邑里不是官方年龄等级；它常被用作品牌/风格名。VS、VSOP、XO 的年限指最年轻的原酒。

ARMAGNAC / 雅文邑AOC + 产区 + 年份

雅文邑法定产区主要分 Bas-Armagnac、Ténarèze、Haut-Armagnac；也有 VS、VSOP、XO、Hors d'Age 等年龄标识。与干邑不同，雅文邑常强调单一年份和 vintage。

雅文邑的蒸馏通常一次连续蒸馏，风格更粗粝、香气更宽；不要把干邑的调配逻辑直接套过来。

WHISKY / 威士忌GI + 年份声明

苏格兰威士忌受 GI 保护，但没有“特级/一级”质量阶梯。酒标上的 12 年、18 年指瓶中最年轻原酒的年龄；Single Malt、Blended、Cask Strength 是风格/工艺，不是等级。

“年份越老越好”是错觉。老酒可能过度橡木、低酒精度或已过适饮期。

TEQUILA / 龙舌兰100% agave + 陈年

龙舌兰分 100% agave 与 mixto；按陈年分 Blanco、Reposado、Añejo、Extra Añejo。陈年更久不等于更好，龙舌兰的植物感很容易被橡木盖住。

RUM / 朗姆

朗姆没有全球统一分级；法属马提尼克有 AOC，其他产区更多靠酒标上的 age、vintage、cask finish 和品牌风格。不要用威士忌的“年份”逻辑硬套。

MYTH 01“Grand Cru 一定更好喝。”

它通常是地块或产区头衔。酒庄、年份、储存状态都能改写结果。

MYTH 02“DOCG / AOC 是评分。”

它们是法律分类，规定产地和工艺，不是品鉴分数。

MYTH 03“Reserve 更高级。”

在不少新世界国家，Reserve 没有统一定义，可能只是产品线。

MYTH 04“XO / 年份越老越好。”

XO 是干邑最低陈年标准；老酒可能过橡木、过氧化或已过适饮期。

THE SHORT VERSION

分级是地图，不是评分。先确认它属于法律、产区、酒庄还是时间；再问年份、生产者和储存。最后才是“好不好喝”——而这件事，只能由杯子回答。

本页为编辑整理，不是任何国家法规全文；AOC/AOP、DOCG、DOCa、Prädikat、AVA、GI 等具体规则会更新，以最新产区法规和瓶标为准。18+，适量饮酒。
